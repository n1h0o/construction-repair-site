# Проверки продукта

## Перед выпуском сборки

- `npm run build` — строгая проверка TypeScript и production-сборка.
- `npm run lint` — статический анализ ESLint.
- Вручную в браузере: меню клавиатурой и на мобильной ширине; открытие/закрытие брифа; обязательные поля; добавление площади, города и комментария; отправка в WhatsApp, Telegram, почту и телефон по очереди конфигурации; резервное копирование брифа при пустых контактах; раскрытие вопросов; переходы якорей.
- Проверить 320, 390, 768, 1024 и 1440 CSS-пикселей, отсутствие горизонтального скролла, фокус, контраст и `prefers-reduced-motion`.
- Проверить фактический контент конфигурации перед клиентским использованием: страна, город, телефон, способы связи, география, часы, реквизиты и юридические страницы.

Сайт не включает backend, обработчик формы или хранилище обращений. Поэтому данные брифа остаются в браузере пользователя и передаются только при явном открытии настроенного канала.

## Результаты этой сборки — 24.10.2026

- `npm run build` — пройдено: строгая проверка TypeScript и production-сборка.
- `npm run lint` — пройдено без замечаний.
- `npm audit` при установке — 0 уязвимостей.
- В браузере проверены главная страница, загруженное hero-изображение, русская семантическая структура, меню/якоря, открытие брифа, обязательная валидация двух селектов и подготовка сообщения с копированием в буфер.
- На ширинах 320, 360, 390, 768 и 1024 px измерена ширина документа: горизонтального переполнения нет. На 320 px исправлено переполнение шапки.
- Визуально проверены desktop и мобильная ширина; фотографии корректно переведены в WebP и загружаются в production-сборку. На мобильной ширине дополнительно проверены открытие/закрытие меню и переход к разделу услуг.

Не проверялись клиентские телефон, Telegram, WhatsApp и email, поскольку они специально оставлены пустыми в шаблонной конфигурации. Проверка реальных отправок появится после настройки контактных данных владельца продукта.
