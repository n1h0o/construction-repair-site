# Безопасность и данные

- В форме нет серверного хранилища, аналитики или стороннего form endpoint; передача запускается пользователем.
- Ссылки наружу для открытия нового окна используют `noopener,noreferrer`.
- Поля ограничены длиной; площадь ограничена положительным числом.
- Не помещайте персональные данные, токены, доступы, реальные клиентские сведения или секреты в `src/config.ts`.
- Публичный продукт не ставит cookies и не использует сторонние трекеры.
- Перед подключением CMS, CRM, аналитики или формы на сервере нужно отдельно спроектировать согласие, политику хранения и защиту данных для страны заказчика.
