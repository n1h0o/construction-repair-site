# Дизайн-направление DEMO-SITE-01

**Brief:** продуктовый маркетинговый сайт для подрядчика по ремонту/строительству в СНГ. Аудитория — домовладельцы, которым надо понять масштаб работ, доверие к процессу и как запросить смету. Главная цель — начатый разговор по телефону/настроенному мессенджеру. Риск — недостоверные обещания и ощущение типового «ремонт под ключ». Прямой build на основе исследованных Refero Styles, без набора тестовых вариантов.

## Reference lock

**Основа:** документальная архитектурная фотография и монохромный холст MANNA, структурная дисциплина и тонкие линии Spacelab. Пользователь ранее подтвердил бумажно-синюю палитру для сайта студии; для продукта ремонтной компании оттенки уточняются по реальным изображениям материалов и интерьеров, не копируются автоматически.

**Сохраняем:**
- крупное реальное изображение помещения или этапа работ — только из разрешённых материалов; иначе сначала используем специально созданные демонстрационные изображения и не подписываем их как завершённые проекты;
- читаемый гротеск, строгие заголовки и просторную сетку;
- визуально иерархичные услуги и этапы вместо одинаковых рекламных карточек;
- очевидный телефон/мессенджер на mobile;
- сдержанный строительный акцент (цвет из реального материала/фактической бренд-палитры), без шаблонной ярко-оранжевой полосы.

**Не переносим:** точные цвета/wordmark/макет референса, вымышленные проектные фотографии, неподтверждённые награды/гарантии, универсальные цены за квадратный метр.

## Паттерны и решения

| Решение | Источник | Роль | Причина |
|---|---|---|---|
| Полноформатная предметная архитектурная фотография | Refero Styles MANNA | Визуальное доказательство работ; использовать только подтверждённый материал | Точный вид работ важнее декоративного UI |
| Тонкие линии, ясная сетка, один акцент | Refero Styles Spacelab | Организация и CTA, без конкурирующей графики | Быстро сравнивать услуги и следующие шаги |
| Переход от изображения к читаемым подписям/секции | Refero Styles Anuc Home | Галерейный ритм, адаптированный под сервисный сайт | Показывает процесс предметно |
| Видимые контакты и без навязчивого квиза | Исследования выбора услуг и сайты региона | Звонок/мессенджер доступны; бриф опционален | Каналы поведения отличаются по рынку и аудитории |

## Токены и media plan

Финальные CSS-токены фиксируются после выбора визуальных материалов для продукта. Предварительно: светлый известковый/бумажный холст, тёмный угольный текст, один сине-графитовый или материал-акцент; без нескольких градиентов и без цветных вымышленных скриншотов. Радиусы малые, тонкие разделители, тени только если доказывают иерархию. Шрифты локальные и лицензированные для web.

Медиа: приоритет разрешённым фотографиям готовых помещений и хода работ. Для продуктового демо можно создать авторские иллюстративные интерьерные изображения; они должны быть обозначены как визуализация, не как портфолио завершённых объектов. Все права и источник — в `assets.md`.
