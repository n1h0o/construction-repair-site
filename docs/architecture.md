# Архитектура

Одностраничное React-приложение на TypeScript/Vite. `src/config.ts` хранит настраиваемые факты компании, услуги и ответы; `src/App.tsx` реализует секции и клиентский сценарий брифа; `src/styles.css` содержит визуальную систему и адаптивные правила. Изображения и favicon находятся в `public/`.

Обращение формируется локально в браузере. Приоритет канала: WhatsApp → Telegram → email → телефон → копирование брифа. Скрытый endpoint и передача данных на сервер отсутствуют. Публикация не выполняется в рамках этой разработки.
