# Дом / Проект — сайт строительной и ремонтной компании

Готовый продукт для малых и средних компаний по строительству и ремонту. Подходит для настройки под выбранную страну и город в СНГ. Сайт полностью адаптивен, включает услуги, портфолио проектов студии, этапы работ, ответы на вопросы и локальный бриф обращения.

## Возможности

- Русскоязычная витрина с адаптивной навигацией.
- Услуги, план работы и демонстрационные проекты студии.
- Бриф с проверкой полей. Сайт не показывает вымышленные цены, отзывы, адреса или клиентские объекты.
- Передача брифа только через настроенный WhatsApp, Telegram, электронную почту или телефон; если контакты не добавлены — бриф можно скопировать.
- Настройки компании в одном файле. Пустые контакты и геоданные не подменяются вымышленными значениями.
- Семантическая разметка, клавиатурная навигация, видимый фокус и поддержка `prefers-reduced-motion`.

## Запуск

Требования: Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev
```

Проверка production-сборки:

```sh
npm run build
npm run lint
npm run preview
```

## Настройка компании

Измените `src/config.ts`: название, специализацию, страну, город, телефон, email, ссылки WhatsApp и Telegram, валюту, географию выезда, реквизиты и часы. Пустые значения скрывают соответствующие сведения. Контактные сценарии не требуют серверного API.

Перед использованием заполните юридические тексты и проверьте требования страны заказчика. Обновите title/description, OG image, фактический домен и `public/sitemap.xml` (сейчас в сборке домен не закреплён). Подробности — `launch-checklist.md`.
