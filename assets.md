# Материалы проекта

## Демонстрационные проекты студии

- `public/images/residence-editorial.webp` — авторская генерация OpenAI image generation, 24 октября 2026; жилой интерьер.
- `public/images/bathroom-editorial.webp` — авторская генерация OpenAI image generation, 24 октября 2026; интерьер ванной.
- `public/images/house-editorial.webp` — авторская генерация OpenAI image generation, 24 октября 2026; загородный дом.

Изображения созданы специально для портфолио проектов студии и оптимизированы в WebP для быстрой загрузки. `npm run assets:build` проверяет наличие всех файлов, production-сборка запускает эту проверку автоматически. Исходные генерации сохранены отдельно от рабочей ветки продукта. Сторонние фотографии, клиентские данные и неподтверждённые истории не использованы.

## Шрифты и иконки

DM Sans и Manrope загружаются через Google Fonts. Для Lucide React используется пакет с лицензией ISC. Favicon — SVG проекта.
